# Ferretería Mr. Natsuky's

Sistema para una cadena de ferreterías en Guatemala, El Salvador y Honduras (regiones norte, sur, oriente y occidente).

- **Base de datos:** Oracle Database 21c Express Edition
- **Aplicación:** Node.js + Express
- **Curso:** Base de Datos, sección A, Universidad Mariano Gálvez
